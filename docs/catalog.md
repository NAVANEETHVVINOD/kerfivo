# Public catalog seed

The initial repository includes three original SVG examples under catalog/assets/, declared MIT under the root LICENSE. They are examples of editable artwork, not tested production jobs. No speed/power/material presets accompany them. Semantic group IDs suggest intended operations, but a real importer must ask the operator to confirm assignments and validate geometry.

catalog/index.json records schema version, ID, title, categories/tags, physical dimensions, relative asset path, author, license, source and SHA-256. Metadata uses the drawing canvas size; it does not assert cut-piece tolerance. Each downloaded file should be checked against a manifest from a reviewed pinned repository commit; a hash from an untrusted manifest alone does not establish authenticity.

Anyone can browse/clone/download this public repository and propose licensed contributions through pull requests. A desktop sync/search/cache client remains to be implemented. No independent upload service, paid hosting, unlicensed collection, or auto-applied machine settings are included.

Search/use categories proposed for expansion: badges/tags, signage, ornaments, education, boxes/joinery, art, electronics enclosures and calibration. Catalog licensing/units/geometry and moderation review precede inclusion. Staff-tested material recipes remain a separate local dataset.
