# Windows pilot acceptance

The local installer is an unsigned early offline pilot. Native installation/window/IPC acceptance has **not** been performed by the agent: native computer control is unavailable in this session. Do not close GitHub #7/#18 or publish application code based solely on core tests and browser previews.

## Build and core evidence

Current checks passed: Vue/TypeScript production build; 9 Rust unit tests; 9 native-core integration tests; 1 explicit real GitHub catalog download/cache/reopen test (19 total). All tests ran with `--include-ignored`, so the network test was actually executed. The public catalog revision tested was 917701bf0b18f145eaa546b69b47d20dcef3f927. Content hashes and licenses of all three original designs matched.

Independent read-only reviews prompted fixes for curves/visibility, unsupported planes, bounded geometry construction/repetition/comparison work, empty output, stale async loads/imports/previews/images, text outline parity, range/checkbox undo and missing operation groups. Self-intersections, kerf and many full editor features remain explicit backlog work.

## Actual native journey to run

1. Install/start the pilot on Windows; record version, WebView2 availability and any launch errors. The Home page must appear without the browser-preview banner.
2. New Project → set workpiece size/material/anchor → Design → add rectangle/circle/text. Edit numeric XY/width/height/rotation; duplicate/delete/undo/redo must preserve measurements and objects.
3. Import the supplied minimal-tag SVG (60 × 30 mm), a declared-unit and unitless DXF, PNG and JPEG. Unsupported content must report an error, rather than silently disappearing or becoming cuts. Select explicit DXF units where absent.
4. Adjust brightness/contrast/invert/dither on an image. Inspect processed output; changes must preserve source pixels, be undoable and invalidate prepared geometry.
5. Assign image/vector score/cut operations, enter/clear speed, set passes/interval, reorder operations and generate Preview. Fix out-of-workpiece/open-cut errors. The preview must show actual prepared paths and current revision.
6. Save → return to Projects → quit/start → reopen. Names, dimensions, artwork, settings, operations and revision must match the saved document.
7. Sync the real public catalog, inspect author/license/revision, close/start without network and import the cached tag. Record actual window behavior and failure messages.
8. Position must keep Home/Jog/Z/Frame/Origin/Start disabled and explain unknown hardware. No native machine communication is present.
9. Inspect both themes, optional red, keyboard focus, range/checkbox undo, and minimum window size. Switch documents/selection while preparation/import/image/text work is pending; obsolete results must not overwrite the current document.

No machine should be operated until #1 identity and #4 commissioning pass. These tasks require observed actual board/driver/capability behavior and a qualified local operator. A successful pilot install would validate the editor, not the machine adapter.
